# International Students' Mental Health Analysis (SQL)

Analysis of survey data from a Japanese international university, exploring
how length of stay affects international students' average scores on the
PHQ-9 (depression), SCS (social connectedness), and ASISS (acculturative
stress) tests.

## Tools
SQL (PostgreSQL), DataCamp DataLab

## Files
- `analysis.sql` – the main query
- `student-mental-health-analysis.ipynb` – full workbook with results
